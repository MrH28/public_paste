# Material Final — Data Science para Ciências Agroambientais

## Tema
Predição de atributos físicos do solo com Python, VS Code e Jupyter.

## Organização
- 9 capítulos em DOCX
- 10 notebooks `.ipynb`
- `requirements.txt`
- notebooks com dados sintéticos de demonstração no início do fluxo

## Observação científica
Os notebooks são didáticos e utilizam dados sintéticos para permitir execução imediata. Para a versão de pesquisa, substitua-os por dados reais, documentando origem, protocolo espectral, atributos laboratoriais, unidades, pré-processamento e critérios de validação.

## Fluxo
Importação → Controle de qualidade → EDA → Pré-processamento espectral → PCA → Clusterização → Engenharia de atributos → Baseline → RF/XGBoost → Validação → SHAP → Aplicação espacial/transferência.

Demattê, J. A. M. et al. The Brazilian Soil Spectral Library (BSSL): A general view, application and challenges. Geoderma, 354, 113793, 2019. DOI: 10.1016/j.geoderma.2019.05.043.
